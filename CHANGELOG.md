- **Real PyInstaller build executed end-to-end** on Linux via `scripts/deploy/build-server.sh`, producing a one-file `HHMS-Server` executable (~55 MB) that was then smoke-tested as an actual frozen process against a fresh `HHMS_APPLICATION_ROOT`.

SQLAlchemy imports the DBAPI lazily at engine-creation time so PyInstaller's static analysis cannot see it; `HHMS-Server.spec` now lists `aiosqlite` and `sqlite3` as hidden imports. Verified over real HTTP: `/health` reports the VERSION release string, alembic chain reaches `0028` inside the binary, bad-credential login returns structured 401 (async DB stack healthy), `/health/discovery` payload matches the served port.
- New QA suite `backend/tests/test_batch106_exe_build_qa.py` (8 tests): six always-on static gates locking in each build defect, plus two opt-in tier-2 tests (`HHMS_RUN_EXE_BUILD=1`) that run the full build and the frozen first-run HTTP contract; tier 2 verified green locally (real build + smoke in 76 s).
