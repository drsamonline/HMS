# HHMS Print Standards

This document defines standards for all printable reports and documents in HHMS.

---

## Overview

Printing is a core feature of HHMS (Milestone 4). All printable documents must follow these standards to ensure consistency, professionalism, and usability.

---

## General Principles

### 1. Print First Design
- All reports designed for print first, screen second
- WYSIWYG print preview
- No hidden elements in printed output

### 2. Paper Standards
- Default: A4 paper size
- Alternative: Letter size (configurable)
- Margins: 1 inch (2.54 cm) on all sides

### 3. Black and White Compatible
- All prints must be legible in grayscale
- Avoid color-dependent information
- Use patterns/shading for differentiation

---

## Header Requirements

Every printed document must include:

1. **Hospital/Clinic Logo** (top-left or center)
2. **Hospital/Clinic Name** (prominent)
3. **Hospital/Clinic Address & Contact** (below name)
4. **Document Title** (clear and descriptive)
5. **Print Date/Time** (auto-generated)
6. **Page Numbers** (format: "Page X of Y")

---

## Footer Requirements

Every printed document must include:

1. **Confidentiality Notice** (if applicable)
2. **Generated By** (system name and version)
3. **Authorized Signature Line** (if required)

---

## Font Standards

### Body Text
- Size: 11pt or 12pt
- Font: Serif or Sans-serif (readable)
- Line spacing: 1.15 or 1.5

### Headings
- H1: 16pt, Bold
- H2: 14pt, Bold
- H3: 12pt, Bold

### Tables
- Header: 10pt, Bold
- Body: 9pt or 10pt
- Borders: Visible

---

## Table Standards

1. **Column Headers**: Clear, concise labels
2. **Alignment**: 
   - Text: Left-aligned
   - Numbers: Right-aligned
   - Currency: Right-aligned with currency symbol
3. **Row Alternation**: Light shading for readability
4. **Borders**: Minimal but visible
5. **Page Breaks**: Avoid splitting rows across pages

---

## Document-Specific Standards

### Prescription Format
- Patient details (name, age, gender, UHID)
- Date of consultation
- Chief complaints
- Prescribed remedies (potency, dosage, frequency)
- Instructions for patient
- Doctor's signature line
- Next appointment date

### Patient Report Format
- Patient identification section
- Medical history summary
- Visit history table
- Treatment summary
- Current status

### Billing Format
- Itemized list of services
- Quantities and rates
- Taxes (if applicable)
- Total amount (prominent)
- Payment received
- Balance due
- Payment terms

---

## Technical Requirements

1. **Print Dialog**: Standard browser/system print dialog
2. **Print Preview**: Available before printing
3. **PDF Export**: All printable documents exportable to PDF
4. **Batch Printing**: Support for multiple documents
5. **Print Queue**: Track pending prints

---

## Quality Assurance

Before any print feature is marked complete:

- [ ] Test print on A4 paper
- [ ] Test print on Letter paper
- [ ] Verify black and white legibility
- [ ] Check page breaks
- [ ] Verify all headers/footers present
- [ ] Confirm font sizes are readable
- [ ] Test PDF export
- [ ] Verify alignment and margins

---

Print templates are stored in:

```
templates/reports/  - Report templates
```
