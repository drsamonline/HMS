# Client Patient Workspace — Batch 08

This batch extends the authenticated client with a real patient workspace.

## Scope
- Search/list existing patients.
- Open an individual patient.
- View core demographic data.
- Register a new patient through the existing backend patient API.
- Provide stable navigation slots for Clinical, IPD, Billing and MRD modules.

The navigation slots are intentionally lightweight. They identify the future module boundaries but do not claim those modules are already implemented in the client.
