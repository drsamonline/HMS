# Role guides

One page per role. Written for somebody on their first day, who has never seen this
software and is slightly afraid of it.

Each guide has the same shape, because a guide that invents its own shape is a guide
nobody reads twice:

- **What you see when you log in** — the home screen, and why it is that one
- **Your first hour** — the smallest set of things to do before you touch a real patient
- **Your first week** — what to learn next, in the order it will come up
- **What you must never do** — the four or five mistakes that cost a hospital something
- **What the software will not let you do** — the boundaries, so a refusal is expected
  rather than alarming

Two things are true of every role and are not repeated in every guide:

**Your menu is not the whole product.** The sidebar shows only the screens your role
can open, grouped by the part of the hospital they belong to. If a colleague has a
screen you do not, that is the role working, not a fault to report.

**Every change you make is recorded.** Who, what, before and after, with the request
id. That is not surveillance; it is what lets a hospital answer an assessor, and it is
why "I did not do that" is a claim the system can check.
