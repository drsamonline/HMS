# Statistics

Every number here names what it counts and what it divides by. If a definition
surprises you, the definition is the useful part of the screen.

A ratio with nothing to divide by reads **no data**, never zero. No admissions this
month and zero per cent of admissions are different statements.

The trend is drawn in whole calendar months. A gap in the line is a month with no
data, not a month with a value of zero.
