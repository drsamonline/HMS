# Client Inventory & Stock Workspace — Batch 31

Adds an administrator-facing inventory workspace backed by the existing inventory-item and stock-transaction APIs.

Capabilities:
- search/list inventory items
- create and update inventory items
- activate/deactivate items
- view stock transaction history
- record Receipt, Issue, Return and Adjustment transactions

This is separate from medicine StockBatch dispensing. Medicine dispensing remains part of Pharmacy.
