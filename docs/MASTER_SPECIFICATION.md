# HHMS Master Specification v1.0

## 1. PURPOSE

HHMS (Homeopathic Hospital Management System) is a lightweight, offline-first management system designed for small to medium homeopathic hospitals. It streamlines patient registration, clinical consultation, prescription management, pharmacy operations, inventory tracking, billing, IPD management, and MRD file tracking while maintaining simplicity, modularity, and ease of use.

## 3. MODULES

### Core
**Purpose:** Provide system foundation and user authentication.
**Main Functions:**
- User login/logout
- Role-based access control
- Dashboard overview
- System notifications

### Patients
**Purpose:** Manage patient registration and demographic information.
**Main Functions:**
- New patient registration
- Patient search and retrieval
- Update patient details
- Patient ID card generation

### Clinical
**Purpose:** Support doctor consultation and case recording.
**Main Functions:**
- Record symptoms and diagnosis
- Track case history
- Add clinical notes
- View previous consultations

### Prescription
**Purpose:** Create and manage homeopathic prescriptions.
**Main Functions:**
- Select remedies from database
- Define potency and dosage
- Add instructions and advice
- Print prescription documents

### Pharmacy
**Purpose:** Dispense medicines and track pharmacy stock.
**Main Functions:**
- View prescribed medicines
- Dispense medicines to patients
- Update stock after dispensing
- Track pending prescriptions

### Inventory
**Purpose:** Manage medicine stock and purchases.
**Main Functions:**
- Add new stock entries
- Track stock levels
- Generate purchase orders
- Alert low stock items

### Billing
**Purpose:** Handle patient billing and payments.
**Main Functions:**
- Generate bills for services
- Record payments
- Track outstanding balances
- Print payment receipts

### IPD
**Purpose:** Manage inpatient admissions and stays.
**Main Functions:**
- Admit patients to wards
- Track bed allocation
- Record daily progress notes
- Discharge patients with summary

### MRD
**Purpose:** Maintain medical records department files.
**Main Functions:**
- Assign file numbers
- Track file movement
- Store consultation records
- Retrieve historical files

### Reports
**Purpose:** Generate operational and clinical reports.
**Main Functions:**
- Daily patient statistics
- Medicine consumption reports
- Revenue summaries
- IPD occupancy reports

### Administration
**Purpose:** Configure system users and permissions.
**Main Functions:**
- Create/manage user accounts
- Assign roles and permissions
- Audit user activity
- Backup system data

### Settings
**Purpose:** Customize system parameters.
**Main Functions:**
- Configure hospital details
- Set printing templates
- Define report formats
- Manage lookup tables

## 6. USER ROLES

- **Reception:** Register patients, schedule appointments, manage front-desk operations.
- **Doctor:** Conduct consultations, record diagnoses, create prescriptions.
- **Pharmacy:** Dispense medicines, manage pharmacy stock, update inventory.
- **Store:** Handle inventory purchases, track stock levels, manage suppliers.
- **Administrator:** Manage users, configure system settings, oversee operations.
