# HHMS Project Index

This document provides a comprehensive navigation guide for the entire HHMS repository.

---

## Repository Structure Overview

```
HHMS/
├── .ai/                    # AI session context and project governance
├── .github/                # GitHub configuration and templates
├── docs/                   # Project documentation
├── backend/                # Backend application code
├── frontend/               # Frontend application code
├── database/               # Database schema and migrations
├── tests/                  # Test suites
├── scripts/                # Utility and setup scripts
├── assets/                 # Static assets (logos, icons, screenshots)
├── templates/              # Print and report templates
├── tools/                  # Development tools
├── README.md               # Project overview
├── LICENSE                 # Proprietary EULA v1.0
├── CHANGELOG.md            # Version history
├── ROADMAP.md              # Project milestones
├── CONTRIBUTING.md         # Contribution guidelines
├── SECURITY.md             # Security policies
└── VERSION                 # Current version number
```

## Folder Purposes

### `.ai/` - AI Governance
Contains all AI-related context files for maintaining continuity across development sessions.

| File | Purpose |
|------|---------|
| `PROJECT_CONSTITUTION.md` | Locked project principles and rules |
| `PROJECT_STATE.md` | Current milestone, objective, and status |
| `AI_CONTEXT.md` | Background context for AI sessions |
| `CODING_RULES.md` | Coding standards and best practices |
| `PROGRESS.md` | Overall progress tracking |
| `TODO.md` | Milestone checklists and pending tasks |
| `SESSION_LOG.md` | Session-by-session development log |
| `DECISIONS.md` | Architectural and design decisions |
| `PROMPTS.md` | Template for recording AI prompts |
| `QWEN_RULES.md` | Instructions for AI assistant sessions |
| `REVIEW_CHECKLIST.md` | Task verification checklist |
| `PROJECT_INDEX.md` | This file - repository navigation |
| `MODULE_STATUS.md` | Module progress dashboard |
